## Exact migration 009 schema

`009_quotation_documents.sql` adds:

1. `commercial_documents.fees jsonb NOT NULL DEFAULT '[]'`, constrained to a JSON array. Each fee stores identity, description, original amount/mode/treatment, calculated amounts, VAT snapshot and, on partial invoices, allocation details.
2. `commercial_documents.quotation_snapshot jsonb`, nullable for existing documents; stores template version and disclaimer.
3. `commercial_documents.copied_from_id uuid`, nullable foreign key to commercial_documents.
4. `quotation_defaults`: UUID primary key, unique true singleton flag, integer version, notes, disclaimer, updated_by user reference and updated_at timestamp. Audited inserts/updates, deletion protection, no PUBLIC privileges.

No existing business row UPDATE/DELETE, reset, reseed, number replacement or historical financial recalculation. The new settings table starts empty. The migration runner registers 009 after 008. Existing non-Draft immutability protection automatically covers the new document fields.
